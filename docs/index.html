Workflow

三步完成

让 Mac 压缩解压便捷、优雅。

  1. 01 选中文件 拖入或点选文件 / 文件夹 / 压缩包
  2. 02 选择操作 压缩、解压或预览，按需设置密码与分卷
  3. 03 一键完成 多核处理，结果直接在 Finder 中打开
